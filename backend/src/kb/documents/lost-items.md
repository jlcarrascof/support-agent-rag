# Lost Items After a Ride

If a customer leaves an item in a vehicle, support can share a contact request with the driver without revealing either party's phone number directly.

Drivers are not obligated to return items immediately, but are expected to respond to a lost item request within 24 hours. If a driver doesn't respond within that window, the case is escalated to a regional support supervisor.

There is no guaranteed recovery for lost items — the app only facilitates contact between the customer and driver, it does not hold or store lost items itself.
