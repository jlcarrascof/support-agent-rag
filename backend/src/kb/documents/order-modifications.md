# Modifying an Order After Placing It

Once an order is placed, items cannot be added or removed through the app — the restaurant has already started preparing it based on the original order.

Address changes are only possible if the order hasn't been picked up by a courier yet. Changing the address after pickup requires contacting support directly, and may result in an additional delivery fee depending on the distance.

Cancelling an order after the restaurant has started preparing it is subject to a partial charge to cover food costs already incurred.
