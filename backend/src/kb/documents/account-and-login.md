# Account and Login Issues

If a customer can't log in, the most common cause is an expired verification code. Codes are valid for 10 minutes and a new one can be requested without any waiting period.

Phone number changes require verifying the new number via SMS code before the account is updated. Email changes follow the same process but use a confirmation link instead.

If an account is locked due to repeated failed login attempts, it unlocks automatically after 30 minutes, or immediately if the customer resets their password.
