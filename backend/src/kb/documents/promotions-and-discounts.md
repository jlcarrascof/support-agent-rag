# Promotions and Discounts

Promo codes can only be applied before checkout, not retroactively to an already placed order. Each promo code has its own minimum order amount and expiration date, both shown when the code is entered.

A customer can only use one promo code per order, and most first-time-user codes can only be redeemed once per account (verified by payment method and device, not just account email).

If a promo code fails to apply with no visible error, it has usually already expired or reached its total redemption limit across all users.
